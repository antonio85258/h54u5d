# Практическая работа: фильтрация и сортировка связанных данных

Проект выполнен на Node.js, Sequelize и SQLite.

## Установка

```bash
npm install
```

## Запуск

```bash
npm start
```

В проекте реализованы пять заданий:
1. Пользователи с постами после заданной даты.
2. Авторы, включая авторов без книг.
3. Студенты с курсами, имеющими больше 3 кредитов.
4. Заказы с товарами в количестве больше 2.
5. Активные пользователи с опубликованными постами.

Тестовые данные создаются автоматически при запуске.
